¿No hay ninguna buena?

En Ajustes → Accesibilidad → Contenido leído → Voces → Español se pueden descargar voces «mejoradas» o «premium». Según Apple, Safari solo ofrece a las páginas web las voces preinstaladas, así que las descargadas pueden no aparecer aquí aunque estén en el iPhone. Si descargas alguna, vuelve a abrir esta página y mira si sale (etiqueta «Premium» o «Mejorada»). Las voces de Siri tampoco suelen estar disponibles para las webs.
